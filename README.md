# Atlas 3D del cuerpo humano

Recurso educativo interactivo en español para explorar estructuras, órganos y sistemas del cuerpo humano en tres dimensiones.

## Abrir el atlas

El sitio se publica automáticamente con GitHub Pages desde `index.html`.

## Créditos de los modelos anatómicos

- BodyParts3D, Database Center for Life Science, licencia CC BY 4.0.
- Female Atlas v2.0, Human Reference Atlas (HuBMAP) y BodyParts3D, licencia CC BY 4.0.
